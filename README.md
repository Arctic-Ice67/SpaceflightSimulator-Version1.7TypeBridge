# Spaceflight Simulator 1.7 TypeBridge

让**未修改的、按 1.6 编译的 DLL mod** 跑在 **Beebyte 混淆过的 SFS 1.7** 上。

**不改游戏本体，也不改硬盘上的 mod 文件。** 全部工作在内存里完成。
